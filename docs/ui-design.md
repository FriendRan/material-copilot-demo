界面围绕本人负责的对话分流、参数补齐、BOM 合并与异常标记，面向面试官与首次体验者。使用本地 HTML、CSS、SVG 和系统中文字体，不引入外部图片、字体或新的 UI 框架。

## 设计方向

- 产品：帮助体验者通过对话确认 PCB 打样参数，再整理和校验物料清单。
- 性格：冷静、准确、有秩序。
- 场景：工程工作台与可核对的需求单。
- 视觉重点：连续的对话工作区与浅色需求摘要并置；BOM 页面以真实表格和异常状态承载信息。
- 特征：确认前后分开呈现，合并结果保留可点击的原始来源行。

调色板为石墨色正文 `#1d2d40`、次级文字 `#526377`、中性背景 `#f2f4f6`、深海军蓝 `#18364f`、操作蓝 `#2459a9`；琥珀色只表达异常，绿色只表达规则通过。没有营销区、装饰数据图、粒子、循环动画或产品插画。

## 信息与交互

- 顶部保留需求对话、BOM 校验、项目说明三个入口。
- 对话旁的需求单保存五项已确认字段；进度仅随用户确认更新，不根据待确认建议提前增长。
- 设置、分流详情、更多示例与参数变更记录按需展开。对话正文 17px，参数与 BOM 正文 16px，关键提示和表头至少 14px。
- BOM 使用独立工作区，原始数据和合并预览分区展示。数量右对齐，型号和位号保持可读；小屏仅表格内部横向滚动。
- 异常既有文字、边框和字段高亮，也能点击定位，不单独依赖颜色。
- 人工协助保留关闭、继续自助及草稿，不表示已接入真人客服。
- 免费后端唤醒提示继续保留；静态前端和本地 BOM 功能可独立使用。服务端持有 DeepSeek 密钥。

## 操作层级与对话体验

根据实际使用反馈，减少同样的“描边方框＋文字”控件：快捷示例采用轻量的图标文字入口，发送使用有可访问名称的圆形图标按钮，人工协助、示例加载和来源行追溯采用低干扰入口；参数确认和导出仍保留明确的主操作按钮。普通助手回复不再包裹矩形气泡，用户消息保留轻底色区分说话人。

默认页面直接呈现 PCB 打样工作台，不使用宣传口号。仅在首次对话的空状态展示本地 SVG 绘制的板层示意；它不包含真实尺寸、器件识别或性能数据，开始对话后收起。摘要区取消整块深色标题，保留可扫读的字段、确认进度和下一项提示。手机端发送目标为 44px，图标沿用统一线条，并保留文字名称、焦点和键盘操作。

## Unslop 精修记录

按轻量精修处理已有工业风格：去除英文装饰标签，使用 PCB 打样语境的标题；收敛字体粗细与间距，使用中性阴影；让参数值和数量列对齐；保留明确的选择、焦点、确认与异常状态。没有为追求变化而增加业务模块。

## 验证范围

桌面双栏使用同一网格行共享高度，聊天记录采用尺寸隔离与内部滚动，避免历史消息撑高页面；较矮窗口压缩需求摘要的留白，字号保持不变。已补充 7 种视口、6 种状态的 42 个底部对齐检查，最大底部差值为 0 CSS 像素，详见 [布局验收](acceptance/layout-alignment.json)。手机端继续采用上下排列。

保留 51 项自动测试，覆盖业务规则、参数确认与拒绝、页面事件、静态构建、接口与会话边界。隔离浏览器检查包含首屏输入框、参数进度、待确认建议不溢出、跨页状态、异常定位、原生 CSV 下载内容、人工草稿与关闭操作。

已在 1920、1366、768、390、360 像素宽度检查整页溢出；关键内容的实测字号为 17 / 16 / 16px，测量对比度最低为 5.43:1。该测量只覆盖列出的关键内容，不宣称整站完成无障碍认证。视口模拟也不等同于物理手机或 Safari 的全面兼容性验证。
