## 设计方向

- 产品：帮助体验者通过对话确认 PCB 打样参数，再整理和校验物料清单。
- 性格：冷静、准确、有秩序。
- 场景：工程工作台与可核对的需求单。
- 视觉重点：连续的对话工作区与浅色需求摘要并置；BOM 页面以真实表格和异常状态承载信息。
- 特征：确认前后分开呈现，合并结果保留可点击的原始来源行。

调色板为石墨色正文 `#202b36`、次级文字 `#526170`、中性背景 `#f3f5f7`、白色对话面 `#ffffff`、雾灰需求单 `#f8fafc`；深海军蓝 `#18364f` 保留品牌识别，操作蓝 `#2459a9` 集中用于主要操作、选中和焦点。琥珀色只表达异常，绿色只表达规则通过。

## 信息与交互

- 侧栏保留智能客服、BOM 校验、项目说明三个入口；手机从左上角打开导航。
- 对话旁的需求单保存五项已确认字段；进度仅随用户确认更新，不根据待确认建议提前增长。
- 设置、分流详情、更多示例与参数变更记录按需展开。对话正文 17px，参数与 BOM 正文 16px，关键提示和表头至少 14px。
- BOM 使用独立工作区，原始数据和合并预览分区展示。数量右对齐，型号和位号保持可读；小屏仅表格内部横向滚动。
- 异常既有文字、边框和字段高亮，也能点击定位，不单独依赖颜色。
- 人工协助保留关闭、继续自助及草稿，不表示已接入真人客服。
- 免费后端唤醒提示继续保留；静态前端和本地 BOM 功能可独立使用。服务端持有 DeepSeek 密钥。

## 操作层级与对话体验

2026-11-24 客服优先版：首屏改为“你好，我是料知”，以工艺、物料和打样问题建立客服身份，初始不把五项参数进度作为页面主体；开始收集参数后再显示已确认进度。桌面保留全窗口预览，手机在 600 CSS 像素以下采用独立排版：单行客服导航、左对齐欢迎区、自然问题圆角入口和底部紧凑输入栏。设置移入手机导航；人工协助仍可直接打开。

手机需求清单复用同一份已确认状态，通过原生 dialog 从底部展开，支持关闭、背景点击和 Esc，模态状态隔离背景焦点。较短窗口内面板可滚动且关闭入口保持可见；切回桌面时恢复原有侧栏/下方清单。参数确认卡片内可滚动，临时收起次要示例与分流行，为消息和输入保留空间。本文后续精修记录与缩放统计描述历史阶段；本次检查见 README 的当前验证范围。

快捷示例按用户给定参考采用浅灰胶囊入口，带有悬停、焦点与选中状态；点击只填入草稿，编辑或发送后同步取消选择。“先说说，这次要做什么板？”使用加粗标题。发送使用有可访问名称的圆形图标按钮，人工协助、示例加载和来源行追溯采用低干扰入口；参数确认和导出仍保留明确的主操作按钮。普通助手回复不再包裹矩形气泡，用户消息保留轻底色区分说话人。

默认页面直接呈现 PCB 打样工作台，不使用宣传口号。仅在首次对话的空状态展示本地 SVG 绘制的板层示意；它不包含真实尺寸、器件识别或性能数据，开始对话后收起。摘要区取消整块深色标题，保留可扫读的字段、确认进度和下一项提示。手机端发送目标为 44px，图标沿用统一线条，并保留文字名称、焦点和键盘操作。

此前精修完成了配色层级、欢迎区布局、需求清单和表面细节四项。桌面需求单常规宽度为 312px；欢迎内容在空状态靠近输入区，开始对话后仍使用内部滚动。主工作区 16px 圆角、输入区 12px 圆角、示例入口胶囊形；容器使用中性边框，阴影集中于悬浮菜单和弹窗。

顶部“需求清单”展示已确认进度，点击后展开五项参数、变更记录与 BOM 入口。进度与摘要只读取已确认值；展开收起不会应用待确认建议、清空草稿、触发模型请求或修改业务状态。1200px 及以上展开为右侧栏，较窄窗口在对话下方展开。参数值保持右对齐，数量采用等宽数字，未填项维持清晰的灰色。

## 参考图与铺满窗口的布局

2026-11-24 根据用户提供的智能助手界面调整结构，并落实“界面要做满”的要求。沿用料知品牌、工业蓝灰、加粗开场与圆角示例入口，采用固定侧栏、顶部状态栏、居中开场和底部宽输入区。去掉包裹整个对话区的外框与最大宽度限制。

侧栏只提供已实现的需求对话、BOM 校验、项目说明、新建需求与已确认进度，没有添加未实现的会话历史。新建需求保留清空确认，并回到对话；取消不会改动数据。900px 及以下导航为可关闭的抽屉，支持 Esc、背景关闭和键盘焦点循环；人工入口移到顶部，仍保持可见。

顶部状态来自实际配置结果，后端等待提示留在对话区。固定状态栏通过页面内边距留位，避免外边距折叠产生底部空白；9 种窗口检查中，桌面对话区与固定侧栏底边差值为 0 CSS 像素。短窗口保留必要的纵向滚动。

## Unslop 精修记录

继续完善字体层级、BOM 和人工协助窗口：页面及分区标题采用适度加粗，保留开场标题 700 字重；对话正文 17px、物料与需求数据 16px，表头、重要说明和草稿提示至少 14px。使用原有系统字体，没有新增外部字体请求。

原始 BOM 使用稳定列宽、灰色表头、对齐的数量表头与数字，保留数字输入框自带的步进操作。异常以对应字段的琥珀色边框与浅底突出，整行仅保留轻微提示；来源行继续可点击定位。两个表格滚动区都可以通过键盘聚焦，小屏仍仅在表格内部横向滚动。

人工窗口在较宽视口中将协助原因与备注放在左侧、参数及异常预览放在右侧；680px 及以下纵向排列。去除未接入步骤的装饰性流程条，保留明确的本地演示说明。右上角关闭、Esc、草稿、保存后下载 JSON、更新交接单及继续自助的状态行为均保持；保存是唯一主按钮。短窗口操作区随内容滚动，较高窗口保留底部操作栏。

快捷示例继续只填入草稿；输入框已经可见时保持位置，需要滚动时立即按最近边缘定位，避免长滚动与紧接着的菜单操作相互干扰。

按轻量精修处理已有工业风格：去除英文装饰标签，使用 PCB 打样语境的标题；收敛字体粗细与间距，使用中性阴影；让参数值和数量列对齐；保留明确的选择、焦点、确认与异常状态。没有为追求变化而增加业务模块。

## 验证范围

对话记录内部滚动，展开的右侧需求单共享网格行。保留 42 项对话布局检查，并检查 9 种窗口下的铺满、底边、导航抽屉与草稿。桌面工作区和固定侧栏的底边差值为 0 CSS 像素，见 [布局验收](acceptance/layout-alignment.json)。

保留 55 项自动测试，覆盖业务规则、参数确认与拒绝、胶囊示例选择、页面事件、静态构建、接口与会话边界。隔离浏览器检查包含首屏输入框、参数进度、待确认建议不溢出、跨页状态、异常定位、原生 CSV 下载内容、人工草稿与关闭操作。

专项检查使用隔离 Edge 配置，设置浏览器真实页面缩放，并核对 `devicePixelRatio`；不是把截图或 CSS 整体缩放。覆盖 75%、90%、100%、110%、125%、150%、175%、200% 八档缩放和四种桌面窗口，另含六种手机／平板视口。共 471 项界面状态检查通过，见 [响应式验收](acceptance/responsive-review.json)。只修改该测试环境的浏览器配置，没有读取或更改个人浏览器资料。

对应修复包括：菜单依据可见区域选择向上或向下展开，内部可滚动且不遮住自身开关；短窗口人工窗口底部操作改为随内容滚动，关闭按钮保留；长参数和长位号换行；BOM 定位直接滚到字段并处理横向滚动，远距离定位不播放长动画；已保存交接单的长按钮文字在平板宽度下不会撑破页头；原生 `hidden` 状态优先于按钮样式。本轮仅精修配色与布局，字体规格、四项职责和模型接口边界保持不变。

已在桌面及手机视口检查整页溢出；关键内容的实测字号为 17 / 16 / 16px。额外测量人工窗口的标题、字段、草稿及说明后，所列关键内容对比度最低为 5.82:1，见 [字体及交接检查](acceptance/detail-review.json)。该测量只覆盖列出的关键内容，不宣称整站完成无障碍认证。视口模拟也不等同于物理手机或 Safari 的全面兼容性验证。

## 输入聚焦与弹窗统一

手机空会话聚焦输入框时，欢迎区、自然问题示例和空清单入口在约 320ms 内上移淡出；退出输入后恢复，草稿不清空。已有对话不参与欢迎区动画。尊重减少动态效果偏好，输入区随 visualViewport 可见高度布局。此键盘逻辑在浏览器事件模拟中验证，未宣称物理手机键盘全覆盖。

设置、分流说明、更多示例、需求清单、人工协助与操作确认采用相同的白色表面、蓝灰边框、字体、圆角和 SVG 关闭图标。手机需求清单保留底部面板结构。快捷菜单使用浏览器顶层 popover，避免被导航抽屉裁切。清空会话和替换 BOM 改为原生 dialog 承载的站内确认，取消与 Esc 均不执行变更，确认后才更新数据。
