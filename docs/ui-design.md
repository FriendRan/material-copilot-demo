# 工业物料助手界面设计

界面聚焦对话分流、参数补齐、BOM 合并与异常标记四项个人职责。采用冷灰底色、石墨色正文与工业蓝操作色，按任务分开显示信息。

## 参考来源

- [Carbon 数据表格规范](https://www.carbondesignsystem.com/building-blocks/core/components/data-table/specifications)：参考工程数据的字号、层级、分隔与状态表达。
- [Siemens Industrial Copilot](https://press.siemens.com/global/en/pressrelease/siemens-xcelerator-scaling-roll-out-generative-ai-siemens-industrial-copilot)：以工业工程助手的任务语境为方向，不复制其界面或扩展其功能范围。

页面与图标使用本地 HTML、CSS、SVG 实现，不依赖外部字体、图片或第三方品牌资产。

## 信息结构

- 默认打开需求对话，首屏直接展示输入框，右侧保留五项已确认参数。
- BOM 校验作为独立页签，承载示例数据、原始表格、合并结果、异常定位、修复和导出。
- 模型模式、分流详情、更多对话场景与参数变更记录按需展开。
- 职责说明放在独立页面，首页不重复堆叠宣传文案、流程图与能力标签。
- 工业蓝用于选中状态及关键动作；正文使用中性石墨灰，异常使用琥珀色与文字、边框共同表达。
- 页签切换保留已确认参数、待确认建议、输入草稿与 BOM。人工协助的继续自助返回可见的对话输入框。

## 验证

45 项自动测试通过，包含跨页保留待确认参数和草稿，以及从 BOM 页继续自助的场景。

隔离的无界面 Microsoft Edge 另行检查了首屏输入框、参数补齐与确认、跨页状态、BOM 合并与异常定位、修复后的真实浏览器 CSV 下载和内容、人工草稿保留与返回输入焦点。对话和 BOM 页在 1920、1366、768、390、360 像素宽度下均无整页横向溢出。

本地浏览器检查使用构造数据与模拟配置，公网真实模型调用在发布后另外验证。视口模拟不等同于物理设备及 Safari 的全面兼容性检查。

## 文字可读性

对话正文为 17px，参数清单与 BOM 表格正文为 16px，列头、状态及主要提示为 14px。弱化文字统一加深，保留工业蓝灰配色及现有分页布局。关键内容在五种视口下测量了实际前景色和背景色，对比度最低为 5.24:1；同时检查参数确认、分页状态保留、异常修复与浏览器下载。该测量仅覆盖列出的关键内容，不宣称整站完成无障碍认证。

## 组件细节

保持分页、面板位置、工业蓝灰配色和可读性字号不变。用轻量表面阴影与更一致的边框、圆角区分组件层次；统一按钮悬停和按下反馈、输入聚焦、数据行悬停与弹窗层次。数量使用等宽数字便于扫读。不增加装饰图、宣传区块或业务模块，触摸设备和减少动态效果偏好保留对应处理。
