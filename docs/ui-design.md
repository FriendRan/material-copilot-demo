# 面试展示界面设计

这次更新仅优化现有职责演示台的视觉和信息层级，不增加新的业务模块。对话分流、参数补齐、BOM 合并、异常标记及辅助人工交接仍沿用原有逻辑；DeepSeek 请求仍通过服务端处理。

## 参考来源

- [Linear 产品界面与工作流展示](https://linear.app/build)：参考简洁侧栏、明确的标题层级、低干扰分隔线与工作区布局。
- [Intercom Inbox](https://www.intercom.com/inbox)：参考以对话为核心、旁侧展示上下文的工作台结构。
- [Intercom Inbox 的 AI 功能与人工确认说明](https://www.intercom.com/help/en/articles/6955446-ai-features-available-in-the-inbox)：参考让 AI 建议与人的确认操作保持清晰可见。

这些页面用于研究设计思路。Demo 的标识、线性图标、流程示意和页面均以本地 HTML、CSS、SVG 实现，没有复制第三方品牌、插图或整套页面，也没有引入外部字体或图片依赖。

## 本次调整

- 采用浅色工作台与克制的青绿色强调，统一侧栏、卡片、表格、按钮、状态和人工弹窗。
- 首页用简短介绍与流程示意说明价值，提供“开始对话”和四种演示场景入口。
- 对话和已确认参数并列展示；隐藏重复说明，将在线体验说明放到页尾，保留发送数据给 DeepSeek 的提示。
- BOM 原始数据、合并结果、守恒核对和异常定位形成连续的阅读顺序；异常保留文字、边框和定位入口，不仅依赖颜色。
- 手机保留顶部导航、人工协助及关闭按钮；宽表格在容器内部横向滚动，不撑宽整个页面。
- 保留键盘焦点、输入标签、Esc 关闭、草稿保留及减少动态效果的系统偏好。

## 验证

43 项现有自动测试通过。另使用隔离的无界面 Microsoft Edge 验证：

- 参数补齐、确认变更、拒绝改口。
- 同键合并、异常字段定位、修复后实际触发浏览器下载，并检查 CSV 中的元件总需求。
- 人工协助右上角关闭、Esc 关闭及草稿保留。
- 工作台、职责说明与辅助问答页面导航。
- 1920×1080、1366×768、768×1024、390×844、360×780 五种视口无整页横向溢出。

检查过程中发现并修复了平板宽度下表格内隐藏标签导致的页面溢出。浏览器检查使用构造数据，模型配置在本地视觉检查时模拟；上线后的真实模型请求另行核验。视口模拟不等同于物理 iOS/Safari 全面兼容性测试。
