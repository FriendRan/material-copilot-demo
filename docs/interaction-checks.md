# 职责展示 Demo 交互复核

日期：2026-11-20（Asia/Shanghai）。范围只包含本人对话入口、参数补齐、BOM 合并与异常标记，保留辅助导出与人工交接。

## 本轮发现与修复

1. 离线规则模式此前直接应用参数，改为与模型模式一致的确认卡片。确认前原值不变，拒绝后保留原值。
2. DeepSeek 澄清回复此前没有四类快捷入口，现补齐，并将澄清选择送回模型，避免偷偷切回规则处理。
3. 未确认建议此前会被下一条输入或模式切换丢弃，现提示先处理建议，新输入留在输入框；确认卡片结束后清空旧按钮。
4. 真实调用中，替料核对思路被误分为一般参数咨询。提示词明确当前消息优先，并区分替料咨询与工艺参数解释。修正后的真实样例通过；不代表所有措辞都已覆盖。
5. 对话模式刷新后恢复；重置保留当前模式并清理旧错误提示。样例修复重复点击显示无需再修复。

## 已通过的功能路径

| 检查项 | 结果 |
| --- | --- |
| 四类意图与不确定意图 | 页面路由标签与处理去向正确；澄清入口可选 |
| 缺项追问 | 先收板层、尺寸、数量，再追问工艺、交期；已填参数保留 |
| 改口确认 | 10 → 20 的建议确认前不生效，确认后只改数量；30 的建议拒绝后仍为 20 |
| 咨询而不修改 | 假设改六层但明确不改，保持四层且不出现变更卡片 |
| 同键合并 | 原始 4 行 → 3 项；同型号同封装合并，不同封装保留 |
| 合并来源 | 原始行按钮聚焦正确的原始行型号字段 |
| 异常定位 | 重复位号两端标记，封装/数量问题聚焦对应字段 |
| 异常修复 | 预设修复和手动逐项修复均重新校验；再引入错误重新拦截 |
| 导出拦截 | 参数不足、待确认、模型等待中或 BOM 异常时不允许导出 |
| 修复后导出 | 两种模板字段顺序及单板数量×板数结果符合预期 |
| 迟到模型回复 | 停止等待后不再写入旧回复或重新提出修改 |

## 验证方式与证据边界

- 自动化单元与页面事件测试：模拟模型响应，运行真实页面脚本，点击与提交实际 DOM 控件，核对状态、焦点和 Blob 内容。
- 真实 DeepSeek 验收：同一个内存 DOM 页面连接本机 `/api/chat`，经过真实服务端 JSON/业务校验；10 条对话样例及合并、定位、修复、两种 CSV 均通过。
- 输出样本：[立创字段顺序 CSV](acceptance/打样需求单_立创.csv)、[嘉立创字段顺序 CSV](acceptance/打样需求单_嘉立创.csv)。样例为 20 块板，3 个单板电阻对应总需求 60 个；未对接厂商下单接口。
- 桌面检查曾读取到真实 Demo 的已确认参数、路由与异常表；原生点击受“窗口最小化 / 用户输入检测 / 无截图目标”阻碍。恢复连接后仍无截图目标，本轮没有宣称完成全部原生浏览器点击、视觉布局或操作系统下载复核。
- 所有验收使用独立构造数据；隔离测试不修改个人浏览器的会话、BOM 或原有下载文件。
